The World in One Page — Sunday, 22 November 2026 (v2): a one-page newspaper front page that sums up the day's world news in a single image. 39 real stories, all reported on 22 November 2026: four illustrated leads (the Gulf F-16 claim, Russia's overnight barrage on Ukraine, missiles into Poland, the capture of cartel boss 'El Chapo Isidro'), a world map with all 39 stories pinned — every pin declustered with a leader line so each number reads — eight picture stories, twenty-seven briefs, a numbers strip, a region count, a UTC timeline and a DATE CHECK footer that names what is not today's news.

v2 rebuilds the entry from scratch: a smoother Arctic coastline on the map, leader-line pins instead of a crowded Gulf cluster, richer coded illustrations for the leads (dusk over the Gulf, Kyiv at night, the Baltic cargo ship, the Sinaloa desert), and real Liberation Serif throughout, rasterised by genfont.py into fonts.bin.

## Run it

mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
